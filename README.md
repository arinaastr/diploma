# НК_Анализ -- Программа для ультразвукового контроля прочности бетона

Десктопное приложение для обработки результатов ультразвукового контроля (УЗК) прочности бетона в соответствии с **ГОСТ 17624-2012** и **ГОСТ 18105-2018**.

---

## Назначение

Приложение автоматизирует построение градуировочной зависимости «скорость ультразвука — прочность бетона», оценку класса бетона и формирование итогового протокола в формате DOCX.

---

## Функциональность

- Импорт данных УЗК из файлов `.xlsx`
- Раздельная обработка данных по **Стволу** и **Конструкциям**
- Построение градуировочной зависимости `R = a·V + b` методом наименьших квадратов
- Итерационная отбраковка выбросов (критерий 2σ)
- Проверка допустимости зависимости по ГОСТ 17624: `r ≥ 0.7` и `S/R ≤ 0.15`
- Вывод параметров: `a`, `b`, `S` (МПа), `r`, `S/R`
- Определение класса бетона по средней расчётной прочности
- Сравнение фактического класса с проектным
- Визуализация градуировочной зависимости с доверительной полосой `±2S`
- Ручное исключение выбросов через чекбокс
- Экспорт протокола в формате **DOCX** (ГОСТ-оформление)
- Выбор периода обследования через календарь

## Порядок работы

1. **Импорт данных** — загрузить один или несколько `.xlsx` файлов с результатами УЗК. Заполнить реквизиты объекта (номер протокола, адрес, период обследования, приборы, НТД, проектный класс бетона).

2. **Расчёт и анализ** — автоматически строится градуировочная зависимость по методу наименьших квадратов. Отображаются параметры `a`, `b`, `S`, `r`, `S/R`, класс бетона. При нарушении критериев ГОСТ выводится предупреждение. Можно пересчитать без выбросов.

3. **Выгрузка протокола** — заполнить ФИО исполнителей, выбрать содержимое (графики, ствол, конструкции) и сохранить в `.docx`.

## Нормативная база

| Документ | Назначение |
|----------|-----------|
| ГОСТ 17624-2012 | Ультразвуковой метод определения прочности бетона |
| ГОСТ 18105-2018 | Правила контроля и оценки прочности бетона |

---

## Критерии допустимости градуировочной зависимости (ГОСТ 17624)

| Параметр | Требование |
|----------|-----------|
| Коэффициент корреляции `r` | ≥ 0.7 |
| Относительное среднеквадратическое отклонение `S/R` | ≤ 0.15 (15%) |

При нарушении любого из критериев использование зависимости для оценки прочности **не допускается**.
